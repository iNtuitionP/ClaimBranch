# Execution plans

ExecPlans preserve self-contained execution context for complex work without
turning temporary progress into product or architecture truth.

- [When and how to use ExecPlans](../PLANS.md)
- [Active plans](active/README.md)
- [Completed plans](completed/README.md)
- [ExecPlan template](../_meta/templates/exec-plan.md)

Plans are not a backlog. Do not create one for every task, and do not infer a
product promise from a planned or active document.
